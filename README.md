# TeamTalk File Generator
A program that generates TeamTalk server files (.tt).
It includes a GUI version made with [AutoHotkey](https://autohotkey.com).
Original author: vrivrixd (see NOTICE.md).
## How to use
When you run the program, it asks for the server details, the account to use, a nickname (optional) and the channel the user should join (optional).
It then saves the file in the folder you choose, with the name you choose.
## Running from source
You need [NVGT (Non Visual Game Toolkit)](https://nvgt.gg) or [AutoHotkey](https://autohotkey.com), both to run and to compile.
## Compiling
To compile with NVGT, press the Applications key or right-click the .nvgt file, choose Compile Script, the platform you want to compile for, and whether you want the Debug or Release version.
To compile with AutoHotkey, press the Applications key or right-click the .ahk file, choose Compile script, or if you prefer, Compile script (GUI).
The GUI option lets you customize the options for compressing the .exe file and the architecture.
